# ubc_hold_carberry

Internal report on upper boundary conditions (UBCs) for H2 escape on Mars. It covers two comparisons:

- the Kepler hold (UBC 2) against explicit RK4 ballistic tracking (UBC 5);
- our reflect, Kepler-hold and free-escape runs against Carberry Mogan et al. (2021), *Planet. Space Sci.* 205, 105302.

Its structure and style follow `../oh2_escape_rerun/` ("Graphite Telemetry", see `design_philosophy.md`). The data follow `refactored/docs/CONVENTIONS.md` 1.0: this report reads analysis-tier files only and never opens a run file.

## Regenerate

Run from `refactored/`, in the `dsmc` env:

```zsh
cd "/Volumes/MyBook/Education and Research/Research/DSMC Exosphere GWs/dsmc_analyzer/refactored"
PY=/Users/josepc/miniforge/envs/dsmc/bin/python
$PY -B registry/build_registry.py                              # registers campaign h2_hold (E7a..E9, Hold_H2_U{1,2,5}_z*_dr250)
$PY -B -m dsmclib.runfile --campaign h2_hold                   # <alias>_run.nc + cards for finished runs
$PY -B -m dsmclib.runfile --campaign h2_ubc_rtop
MPLBACKEND=Agg $PY -B campaigns/h2_hold/compute_analysis.py      # outputs/h2_hold/analysis/*_analysis.nc, tables/*.csv
MPLBACKEND=Agg $PY -B campaigns/h2_ubc_rtop/compute_analysis.py  # outputs/h2_ubc_rtop/analysis/*_analysis.nc

cd docs/reports/ubc_hold_carberry
MPLBACKEND=Agg $PY -B scripts/make_numbers.py   # numbers.tex, tables/*.tex, numbers_status.json
MPLBACKEND=Agg $PY -B scripts/make_figures.py   # figures/*.pdf + 300-dpi *.png
tectonic -o build main.tex                      # build/main.pdf
$PY -B scripts/check_macros.py                  # exits 1 if main.tex/tables use an undefined macro
```

- No number is typed into `main.tex`. Every value comes from `numbers.tex` and `tables/*.tex`, which `make_numbers.py` writes; never edit those by hand.
- A value whose input is missing is written as `\pending{reason}` and listed in `numbers_status.json`, which also appears in Appendix B of the PDF. An input is missing when a run has not finished, has no run file, or its analysis file is older than its run file.
- The "findfont: Apple Chancery" warning is harmless.

## Data sources

The raw tier is read only. Products are regenerated by code.

| Group | Raw run folders | Analysis tier read by this report | Used for |
|---|---|---|---|
| Verification E7a–E9 (collisionless, z_top 2,627 km, 6e4 s) | `~/MarsAtmos-UBC-explicit/verification/runs/<alias>/` | `outputs/h2_hold/analysis/<alias>_analysis.nc`; metrics and collisionless references in `h2_hold_analysis.nc` | §4, Fig. 3 (b, e, f), Fig. 4 |
| h2_ubc_rtop sweep (UBC 1–3, 3e5 s, no hold diagnostics) | `~/MarsAtmos-H2UBC-sweep/runs/<id>/` | `outputs/h2_ubc_rtop/analysis/<id>_analysis.nc` (fixed 100–300 ks window) | §5, §6, Fig. 1, Fig. 2, Tables 4–5 |
| h2_hold campaign (UBC 1, 2, 5, 2e6 s, collisions on) | `~/MarsAtmos-H2Hold-campaign/runs/<id>/`, alias `Hold_<id>` | `outputs/h2_hold/analysis/Hold_<id>_analysis.nc` (steady window; includes the BallisticHold series, dim `hold_time`) | §5–§8, Fig. 1–3, Fig. 5 |
| Paper | `MarsAtmos/docs/Literature/Markdown Parsed/Carberry Mogan et al. 2021 - .../` | `PAPER` dict in `scripts/analysis.py` | constants and digitised values |
| Solver constants | `MarsAtmos-UBC-explicit/Source/MOD_Species.f90` | parsed in `scripts/analysis.py` | VHS d_ref and omega |

- The H2O_* (H2 + O) sweep runs are ignored.
- The campaign run folders also contain `H2_*_run.nc` files, built by `run_config.zsh` under the plain run id. The verification folders also contain retired `*_L1.nc` files. Neither is read; the registry aliases above name the current run files.

## Layout

- `main.tex`: the report.
- `numbers.tex`, `tables/`, `numbers_status.json`: generated; do not edit.
- `scripts/style.py`: palette and UBC style map.
- `scripts/analysis.py`: a loader of the two campaigns' analysis files (run status, per-run reductions in the report's names, hold series, collisionless references, verification metrics), the paper constants (`PAPER`) and small helpers.
- `scripts/make_numbers.py`, `scripts/make_figures.py`, `scripts/check_macros.py`.
- `figures/`, `fonts/`, `build/` (the PDF; `build/audit/` holds the independent recomputation scripts of the audits).
- The campaign analysis is in `refactored/campaigns/h2_hold/` (`compute_analysis.py`, `README.md`).
